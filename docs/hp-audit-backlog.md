## 色憲法の現状 (DESIGN.md v0.4.1)

詳細は [DESIGN.md](../DESIGN.md) を参照。要約:

| トークン | HEX | 役割 |
|---------|-----|------|
| `--color-brand` | #1B5EBE | 基調色（30%枠）。ナビ・見出し・リンク。サイトの「顔」 |
| `--color-navy` | #0F2F5B | ヒーロー背景・フッター・CTAバナー等の濃い面 |
| `--color-ink-dark` | #1A1A2E | 濃色テキストアクセント。カード見出し・ボタンテキスト |
| `--color-accent` | #0E9E96 | ティール。アイコン・強調下線・サービスカード番号 |
| `--color-gold` | #C8A15A | ロゴ `.ai` 細部・区切り線のみ。大面積禁止 |
| `--color-cta` | #EA6A00 | 主要CTAボタン専用 |
| LINE Green | #06C755 | LINE CTA専用 |

**役割分担の要点:**
- Brand (#1B5EBE) = 基調色（面にも線にも使う、30%枠）
- Navy (#0F2F5B) = 濃い面の色（背景用）
- Dark Accent (#1A1A2E) = テキスト/小面積の濃色アクセント（Navyとは用途が異なる）
- 青/オレンジの「アウトライン装飾」は廃止済み。基調色 #1B5EBE 自体は正式採用色
